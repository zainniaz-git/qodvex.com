# Qodvex - Free QR Code Generator (by Code With Zain)
Static site: upload all files to a GitHub repo named `qodvex`, then Settings > Pages > Deploy from branch `main` / root. All paths are relative, so it works under a repo subpath.
After buying a domain: replace `YOUR-DOMAIN.com` in `sitemap.xml`/`robots.txt`, add the canonical tag in `index.html`, set your email in `contact.html`, then submit the sitemap in Google Search Console.
Dependencies: qrcode-generator 1.4.4 (MIT, bundled in assets/qrcode.js), Poppins via Google Fonts (OFL).
Not included: centre-logo feature, ad containers, manifest (omitted to stay reliable).
